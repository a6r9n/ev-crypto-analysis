# Electric Vehicles & Cryptocurrency Analysis

This project refactors my undergraduate coursework (CST2330- Database Analysis for Enterprise Modelling) into a clean and reproducible data science project in R.

It includes the following:
- Net Present Value (NPV) financial modelling
- Linear programming production optimisation
- Exploratory analysis of an EV dataset
- Time-series processing of cryptocurrency candles
- Log-returns computation and plotting
- Clean R scripts for all logic

## How to run
1. Open the project in RStudio.
2. Open `analysis/ev_crypto_analysis.Rmd`
3. Click **Knit**.

[View the full HTML report here](https://a6r9n.github.io/ev-crypto-analysis/ev_crypto_analysis.html)

All datasets are anonymised.
